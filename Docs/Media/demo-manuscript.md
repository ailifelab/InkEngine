# 山间来信

## 第一章 清晨

清晨，窗外的风带来了雨的气息。远处的山藏在薄雾里，屋檐下的水珠一滴一滴落在石阶上。

她推开窗，将一张信纸铺在桌前。昨天读到的句子还留在心里，今天想写下的故事，却从一阵鸟鸣开始。

“如果你也在这里，”她写道，“就能看见雨后山坡的颜色。深绿的是松林，浅绿的是新叶，最远处那一点白，是云停在了山顶。”

写作的时候，时间走得很慢。一个词被轻轻划去，又换成了另一个词。她把长句拆开，让每一次停顿都像窗外的呼吸。

## 第二章 远行

午后，天终于放晴。她带上书和笔记本，沿着河岸走向车站。风吹过树梢，草木的清香一路跟着她。

车站里有人告别，也有人相逢。她坐在长椅上，把早晨的信又读了一遍。读到最后一句时，她微微笑了起来。

纸上的文字有自己的节奏。有些句子适合安静地看，有些句子需要读出声音，才能听见其中细小的犹豫与坚定。

## 第三章 灯下

夜色落在窗前的时候，她回到书桌旁。灯光温暖，茶水还热，白天没有写完的故事正等着继续。

她将信纸放进信封，在封口处画了一片小小的叶子。明天，这封信就会越过河流与群山，抵达远方的朋友手中。

而新的故事，已经在下一页开始。
