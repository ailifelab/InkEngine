# 界面与操作素材

这些素材来自本机已安装的 Ink Engine Mac 0.3.1（6）真实界面。通过 `--ui-testing` 启动的独立资料库，只打开人工编写的 Samples/听读校稿示例.md；未使用个人文稿、设备名单或配对数据。

PNG 为原始窗口截图的等比缩小。GIF 由实际操作的关键状态截图按步骤顺序组成，便于反复查看；不是连续录屏，也不附带声音。reading-demo 展示编辑、阅读、实际 Matcha 播放和暂停；voice-selection 展示模型及同模型音色切换。Mac 截图不用于冒充 iPhone 或 iPad 界面。

仅为控制仓库大小进行缩放和 GIF 调色板编码，没有替换文字、生成界面或模拟不存在的功能。
